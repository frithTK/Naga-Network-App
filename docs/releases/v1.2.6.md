# Naga Network 1.2.6

В этом релизе опубликована сборка **Linux x86_64**:
[NagaNetwork-1.2.6-x86_64.AppImage](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.6/NagaNetwork-1.2.6-x86_64.AppImage).

## Изменения

- Один AppImage содержит интерфейс, naga-control, sing-box, olcRTC и hev.
- При первом запуске встроенный установщик настраивает системную службу через авторизацию ОС. Повторный запуск установленной сборки обходится без новой авторизации.
- Исправлен шаблон systemd; перед установкой проверяется его корректность.
- Обновление из нового клиента скачивает один AppImage, проверяет SHA-256, устанавливает его runtime и перезапускает интерфейс.
- Исправлены гонки и обновление кеша правил, отмена запуска VPN, завершение дочерних процессов, обработка профилей и восстановление системного прокси.
- Усилены проверки скачивания и распаковки обновлений; обновлены компилятор и зависимости движков.
- Добавлены регрессионные тесты и CI для Linux, Windows и Flutter. Исправлены зависимости Linux-теста прокси, освобождение журнала в тесте и проверки Unix-прав при выполнении тестов на Windows.
- В исходники включены iOS-клиенты и инструменты сборки; подписанная iOS-сборка в этот релиз не входит.

## Установка и переход с 1.2.5

Скачайте AppImage, сделайте его исполняемым и запустите:

```bash
chmod +x NagaNetwork-1.2.6-x86_64.AppImage
./NagaNetwork-1.2.6-x86_64.AppImage
```

Если в системе отсутствует FUSE:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./NagaNetwork-1.2.6-x86_64.AppImage
```

Для перехода со старого Linux-клиента 1.2.5 скачайте новый AppImage вручную один раз: его прежний updater требует второй control-файл. Профили используются из прежнего каталога данных. Подтвердите запрос авторизации ОС при установке службы.

## Проверки

Перед публикацией проверяются Go tests/vet/race, Flutter tests/analyze, компоненты установщика и содержимое AppImage, включая версии, целостность файлов и защиту API. Установка системной службы и запуск интерфейса проверены на текущем Linux при подготовке формата AppImage.

Фактический VPN-трафик, tray, cold boot и обновление между разными версиями требуют отдельного стендового прогона. Готовые APK, Windows setup/portable и подписанный IPA для 1.2.6 в этом релизе не публикуются.
