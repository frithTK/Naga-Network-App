# Naga Network 1.2.8 — Windows и Linux

Готовые установщики для Windows x64 и Linux x86_64. Сборка из исходников не требуется.

## Скачать

- [Windows: установщик](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.8/NagaNetwork-1.2.8-windows-x64-setup.exe).
- [Windows: portable ZIP](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.8/NagaNetwork-1.2.8-windows-x64.zip) — распаковать и запустить `NagaNetwork.exe`.
- [Linux: AppImage со встроенным установщиком](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.8/NagaNetwork-1.2.8-x86_64.AppImage) — разрешить исполнение и запустить; при первом запуске подтвердить установку службы.

## Изменения

- Исправлено ожидание применения прав доступа к TUN при установке Linux-службы; добавлено понятное сообщение при ошибке настройки устройства.
- Linux AppImage собирается на Ubuntu 22.04 с совместимым именем константы GLib.
- В обеих сборках есть актуальная проверка задержек серверов: результаты появляются постепенно, проверку можно отменить.
- Windows setup регистрирует elevated-helper; интерфейс работает с обычными правами, а TUN поднимается через helper. Portable без установленного helper запрашивает UAC при подключении.
- Linux AppImage содержит интерфейс, naga-control, sing-box, olcRTC, hev и установщик systemd-службы. Отдельные файлы runtime скачивать не требуется.
- Добавлены воспроизводимая сборка Linux в GitHub Actions и проверки установки пакетов на чистых Windows/Ubuntu.
- Исправлен слишком короткий таймаут теста на 1000 серверов под race detector; код проверки серверов не менялся.

## Установка

Перед обновлением закройте Naga Network. В Windows запустите setup и подтвердите UAC. Для portable используйте отдельную папку и запускайте `NagaNetwork.exe`.

В Linux сделайте AppImage исполняемым и откройте его. Встроенный установщик подготовит службу после подтверждения авторизации ОС; повторный запуск установленного runtime использует готовую службу.

Не запускайте установленную и portable-копии одновременно. Контрольные суммы файлов находятся в `SHA256SUMS.txt`.

## Проверки

- Windows: [сборка и проверка установщика](https://github.com/frithTK/Naga-Network-App/actions/runs/38738904321/job/116435210926). Все 47 файлов установленной программы совпали с portable по SHA-256. Проверены регистрация elevated-helper, запуск sing-box через helper, создание Wintun-интерфейса и удаление программы вместе с задачей helper.
- Linux: [проверка AppImage на Ubuntu 22.04](https://github.com/frithTK/Naga-Network-App/actions/runs/38738146482/job/116432624107). Сверены файлы runtime, проверена установка systemd-службы и права TUN. Повторный запуск не требует второй авторизации. API сообщает 1.2.8, принимает запрос с токеном и отклоняет запрос без него. Создан настоящий TUN-интерфейс без изменения маршрутов CI-машины.
- [Общий CI исходников 1.2.8](https://github.com/frithTK/Naga-Network-App/actions/runs/38738127036): Go tests/vet/race, Flutter tests/analyze и регрессионные тесты упаковки.

Обе платформы собраны из коммита [`7638f22`](https://github.com/frithTK/Naga-Network-App/commit/7638f22748d2ba1e20c3134fc5f71a08ecf25aea), которому соответствует тег `v1.2.8`.

Интерактивный диалог UAC на пользовательском ПК и соединение с конкретным VPN-провайдером в этих CI-проверках не проверяются.
