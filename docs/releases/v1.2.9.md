## Исправления

- Подписки, содержащие только VPN-серверы, больше не блокируют подключение с ошибкой `routing policy requires a direct outbound`. Прямой маршрут для локальных правил добавляется во временную конфигурацию; исходная подписка сохраняется.
- DNS-запросы TUN обрабатываются до правил приложений и обхода локальных сетей. Это устраняет попытки отправлять DNS-адрес туннеля напрямую и ошибку «Этот хост неизвестен» после подключения.
- Если в подписке отсутствует DNS, используются резервные серверы Cloudflare `1.1.1.1`: отдельный UDP-резолвер для имён VPN-серверов и TCP-резолвер через итоговый маршрут для остальных запросов. При выбранном режиме приложений DNS следует итоговому маршруту этого режима. Настройки DNS, заданные провайдером, сохраняются. Cloudflare получает обрабатываемые им DNS-запросы.

## Установка

Перед обновлением закройте Naga Network. В Windows запустите setup и подтвердите UAC: установщик регистрирует elevated-helper, который затем поднимает TUN без повторного запроса UAC. Portable без установленного helper запрашивает UAC при подключении.

В Linux разрешите исполнение AppImage и запустите его. При первом запуске встроенный установщик запрашивает авторизацию для установки службы; последующие запуски используют установленную службу. Все необходимые runtime-файлы включены.

## Проверки

- Локальные регрессионные тесты маршрутизации, DNS, control-plane и адаптера sing-box; статический анализ Go.
- Реальное подключение на Windows с исправленным ядром: VLESS, изменение внешнего IP и успешный HTTPS `generate_204`. Проверка использовала отдельную копию сохранённого профиля и маршрутизировала через VPN только тестовый процесс. После остановки подтверждено восстановление маршрутов, DNS и прокси; исходные профиль и настройки не изменились. Приватные параметры профиля в репозиторий и CI не передавались.
- Пакеты Windows и Linux проходят сборку и проверку установки в GitHub Actions перед публикацией.

На локальной Windows VM отдельные запуски Wintun не уложились в таймаут готовности; повторный запуск завершился успешно. Исправления этого отдельного поведения драйвера данный выпуск не заявляет.
