# Naga Network 1.2.9

- Исправлено подключение профилей без прямого маршрута.
- Исправлена обработка DNS в TUN; резервный DNS — Cloudflare `1.1.1.1`. DNS провайдера сохраняется.

Скачать: [Windows setup](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.9/NagaNetwork-1.2.9-windows-x64-setup.exe) · [Portable ZIP](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.9/NagaNetwork-1.2.9-windows-x64.zip) · [Linux AppImage](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.9/NagaNetwork-1.2.9-x86_64.AppImage).
