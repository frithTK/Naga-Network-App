# Naga Network 1.2.7 — Windows

Готовые сборки для Windows 10/11 x64. Собирать приложение из исходников не требуется.

## Скачать

- [Установщик](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.7/NagaNetwork-1.2.7-windows-x64-setup.exe) — установить или обновить приложение.
- [Portable ZIP](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.7/NagaNetwork-1.2.7-windows-x64.zip) — распаковать в отдельную папку и запустить `NagaNetwork.exe`.

## Изменения

- Результаты проверки задержек серверов появляются по мере готовности; проверку можно отменить.
- Исправлено обновление результатов проверки в окне выбора сервера, сокращены лишние перерисовки.
- В Windows-сборку включены изменения после 1.2.5: обновление приложения с проверкой SHA-256, отдельный portable-updater, исправления запуска и остановки VPN, восстановления системного прокси и обработки профилей.
- Обновлены сборочный Go toolchain и зависимости VPN-движка. В комплекте находятся `naga-control`, `naga-update`, sing-box, Wintun, olcRTC, hev и VC++ runtime.

## Установка

Закройте Naga Network и запустите установщик. Setup запрашивает права администратора и регистрирует helper для TUN. Интерфейс запускается с обычными правами пользователя.

Portable без установленного helper запрашивает UAC при подключении TUN. Не запускайте установленную и portable-копии одновременно.

В этом релизе публикуются Windows setup и portable ZIP. Последняя Linux-сборка доступна в [релизе 1.2.6](https://github.com/frithTK/Naga-Network-App/releases/tag/v1.2.6).

## Проверки

- Windows: `go test -timeout=90s ./...` и `go vet ./...`.
- Flutter: `dart analyze`, 121 успешный тест; три теста пропущены тестовым набором.
- Исправлен тест проверки каталога конфигурации sing-box: он больше не требует Unix-команду `true` и проверяет передачу JSON, рабочий каталог и удаление временных файлов.
- Собраны Windows setup и portable ZIP; каждый файл ZIP сверен с исходным бандлом по SHA-256. Проверены версии установщика и UI.
- Изолированный запуск `naga-control`: API сообщает версию 1.2.7, готовность sing-box и olcRTC и поддержку фоновой проверки серверов; запрос без токена получает HTTP 401.
- В метаданных собранного sing-box подтверждены Go 1.27.2 и закреплённые версии `x/net`, `x/crypto` и `klauspost/compress`.

Установка с UAC, подключение к реальному VPN-серверу и обновление поверх установленной версии в этом прогоне не проверялись.
