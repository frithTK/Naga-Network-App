# Naga Network 1.2.11

- **Linux TUN** перехватывает IPv4 и IPv6, когда IPv6 включён в системе. Это устраняет прямой выход IPv6 в штатной конфигурации. После отключения VPN прежние маршруты восстанавливаются.
- **Импорт профилей** принимает HTTPS-подписки, одиночные ссылки и текстовые или Base64-списки. Поддерживаются варианты VLESS, VMess, Shadowsocks, Trojan, Hysteria2, TUIC и совместимые узлы из Clash YAML. Предпросмотр показывает доступные узлы и причины пропуска, включая Xray FinalMask. Для узлов из Clash YAML применяются правила и DNS Naga.
- **Профили** сохраняют исходную HTTPS-ссылку для обновлений. Добавление отдельного профиля сохраняет текущую VPN-сессию.
- **Подключение** показывает этапы запуска. Автовыбор проверяет запасную группу перед TUIC, а на Linux повторно проверяет узел при смене сети Wi-Fi.
- **Диагностика** показывает активные соединения sing-box, сработавшие правила, цепочки и счётчики трафика в обе стороны.

Перед обновлением закройте Naga. На Linux установщик может запросить авторизацию для обновления системной службы. Для подключения через TUN сначала отключите другой активный VPN.
