# Naga Network 1.2.10

- AmneziaWG: доменный endpoint разрешается до настройки туннеля, готовность ждёт рукопожатия, доступ проверяется HTTPS-запросом через выбранный узел. В строгом ручном режиме туннель остаётся поднятым, если сайт проверки не ответил.
- Замер задержки AmneziaWG идёт через собственный SOCKS, без временного sing-box. На главном экране показывается задержка текущей сессии.
- Linux привязывает исходящий UDP AmneziaWG к текущему uplink. Android защищает эти сокеты через VpnService.
- olcRTC: обновление списка узлов и политика маршрута на Linux не ломают соседние профили.
- Интерфейс учитывает отсутствие сети до подключения.

Скачать: [Windows setup](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.10/NagaNetwork-1.2.10-windows-x64-setup.exe) · [Portable ZIP](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.10/NagaNetwork-1.2.10-windows-x64.zip) · [Linux AppImage](https://github.com/frithTK/Naga-Network-App/releases/download/v1.2.10/NagaNetwork-1.2.10-x86_64.AppImage).

Перед обновлением закройте приложение. Windows setup устанавливает helper; portable без helper запрашивает UAC при подключении. Linux запрашивает авторизацию при первой установке службы.

Проверено: [CI](https://github.com/frithTK/Naga-Network-App/actions/runs/44930724960), [сборка Linux AppImage и Windows setup](https://github.com/frithTK/Naga-Network-App/actions/runs/44930747300). Системный TUN на установленной службе и смена сети на устройстве в эту сборку не входили.
