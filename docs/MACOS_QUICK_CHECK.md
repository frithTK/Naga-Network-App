# Быстрая проверка на Mac

Требуется Mac с Apple Silicon (включая M2) и macOS 14 или новее.

[Скачать DMG](https://github.com/frithTK/Naga-Network-App/releases/download/macos-dev-1.2.9-check1/NagaNetwork-1.2.9-macos-arm64.dmg) · [Файлы сборки и checksum](https://github.com/frithTK/Naga-Network-App/releases/tag/macos-dev-1.2.9-check1). Вход в GitHub не нужен. Проверенный source commit: `6f4e2bf382d2d21d293e0cb2b6de5d9abc233506`.

1. Откройте ссылку скачивания в **Safari или Chrome** и скачайте DMG. Для передачи сборки другому проверяющему отправьте ссылку на релиз.
2. Откройте тестовый DMG и перетащите **Naga Network** в **Программы**. Откройте установленное приложение.
3. Нажмите **«Проверить Mac»**. Если откроются настройки macOS, разрешите Naga работать в фоне. Приложение продолжит проверку автоматически.
4. Дождитесь результата и нажмите **«Скопировать отчёт»**. Передайте этот текст разработчику.

При скачивании файла через Telegram может появиться блокирующая карантинная метка. Если уже возникло «The application can’t be opened», скачайте свежий DMG по ссылке выше через Safari или Chrome. [Разбор этого случая](MACOS_LAUNCH_FAILURE.md).

Терминал, отдельные приложения A/B и перезагрузка для этой проверки не нужны. Если macOS не разрешила открыть само приложение, достаточно передать сообщение об ошибке: встроенная проверка ещё не могла начаться.

При проверке приложение связывается со своей локальной службой, временно регистрирует диагностическую системную службу, проверяет её ответ и удаляет регистрацию. Отмена тоже запускает удаление. При ошибке удаления появляется кнопка **«Завершить проверку»**. Отчёт копируется только по нажатию пользователя; автоматической отправки нет. Профили, токены, журналы и личные пути не включаются.

Это проверка запуска и доступа к системной службе. Рабочее VPN-подключение, TUN/DNS, перезагрузка и обновление службы ещё не проверяются. VPN в этой тестовой сборке недоступен.

Сборка имеет ad-hoc подпись и не прошла нотариализацию Apple. Для первого открытия macOS может потребовать отдельное штатное разрешение в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если оно доступно.

Инженерные сценарии A/B сохранены [отдельно](MACOS_M2_SERVICE_PROBE.md); обычному проверяющему их выполнять не требуется.

Зафиксирован успешный отчёт на macOS 26.2 ARM64: backend, root status службы и удаление регистрации прошли. Способ снятия первоначальной блокировки и отдельное повторение браузерной установки на устройстве не подтверждены. [Исходный отчёт](macos-test-results/2026-10-19-macos-26.2-quick-check.json).
