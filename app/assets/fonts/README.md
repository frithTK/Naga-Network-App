# Inter для интерфейса Naga

Источник: [Google Fonts / Inter](https://github.com/google/fonts/tree/main/ofl/inter),
файл `Inter[opsz,wght].ttf`, получен 2026-09-16.
Лицензия: SIL Open Font License 1.1, полный текст в [OFL.txt](OFL.txt).

Статические начертания созданы через `fontTools.varLib.instancer.instantiateVariableFont`:
`opsz=14`, `wght=400/500/600/700`, `inplace=False`. Геометрия глифов не редактировалась.
Кириллица, включая Ё/ё, присутствует во всех четырёх файлах. Используется семейство
Inter; Microgramma не поставляется. Лицензия включена в assets и LicenseRegistry.
Общий размер TTF — 1 369 144 байта; разовая загрузка сети для шрифта не нужна.
