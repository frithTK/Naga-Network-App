Naga Network — тестовая сборка macOS

Требуется macOS 14 или новее и Mac с Apple Silicon, включая M2.
Перетащите Naga Network в Applications, затем запустите установленную копию.

Доступны запуск приложения, пользовательский backend, импорт профилей и
сохранение настроек. VPN-подключение в этой сборке ещё недоступно:
системная служба VPN пока не подключена к основному приложению.

Сборка имеет ad-hoc подпись и не прошла нотариализацию Apple.
Если macOS блокирует первое открытие, запишите сообщение. Штатное разрешение
для собственного тестового приложения находится в «Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть», если macOS его предлагает.

Профили и настройки: ~/Library/Application Support/Naga Network
Журналы: ~/Library/Logs/Naga Network
Закрывайте приложение через Command-Q перед заменой установленной копии.

Для проверки нажмите «Проверить Mac» в основном окне. Если откроются настройки
macOS, разрешите Naga работать в фоне. Остальные шаги выполняются автоматически.
После результата нажмите «Скопировать отчёт» и передайте текст разработчику.
Терминал, отдельные приложения A/B и перезагрузка не нужны.

Проверка временно регистрирует диагностическую службу только с операцией status,
проверяет ответ и удаляет регистрацию. Отмена также запускает удаление;
при ошибке доступна кнопка «Завершить проверку». Маршруты и DNS не меняются.
В отчёт не включаются профили, токены, журналы и личные пути.
