# Apple platforms

iOS-клиент на Linux собирается из [`ios/`](../../ios) через [xtool](https://github.com/xtool-org/xtool). Документация: [`docs/platforms/IOS.md`](../../docs/platforms/IOS.md).

[`app/ios`](../../app/ios) — запасной Flutter/Xcode каркас. macOS-десктоп в этом контуре нет: десктоп — Linux и Windows.
